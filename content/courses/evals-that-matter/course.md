How do you know your prompt works? Not from one good reply. This course
turns "it looked fine when I tried it" into a habit you can trust: test cases
from real failures, code graders first, an LLM judge you've checked against a
person, and a regression set that runs on every change. Every exercise runs
live on Claude, and most are graded the way the lesson teaches.
