This is where the build-along starts. Over five lessons you'll build Klippy,
a small assistant that runs on Cloudflare and answers with Claude. You'll
start from an empty folder and finish with a live Worker on the internet,
locked so that only you can spend your model budget. Every step is small,
shown in full and explained, and every lesson has a git tag to catch up from.
